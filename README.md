# 哈希倒数5个数字｜单段优选形态系统

## 数字顺序修复
从哈希最右边开始向左数，找到5个数字后直接按这个顺序使用，不再反转。

例如原字符串末尾数字从左到右为：
`0 7 8 5 6`

从最右边开始数得到：
`6 5 8 7 0`

因此开奖结果为：
`65870`

拆分：
- 前三：658
- 中三：587
- 后三：870

## 下一期推荐
不再同时推荐前三、中三、后三。

系统会比较：
- 10个方案
- 每个方案的前三、中三、后三
- 共30个独立候选

根据20/30/50期独立中奖率和连错，只选择一个最高的推荐。

例如：
- 前三综合中奖率最高
- 下一期只显示：前三预测 对子、杂六

中三和后三不会同时显示为下一期推荐。

## 独立中奖
若推荐前三“对子、杂六”，实际前三开出对子或杂六任意一个，前三即中奖。

## 保留功能
- 每5秒刷新
- 10个方案
- 三段独立冻结统计
- 下一期开奖前冻结
- 开奖后固定中/未中
- 投注金额、赔率、盈利计算
